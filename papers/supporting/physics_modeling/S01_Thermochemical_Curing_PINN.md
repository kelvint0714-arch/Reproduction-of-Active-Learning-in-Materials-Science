# S01｜热化学固化 PINN：复合材料固化过程物理模型

## 论文与资源

- 论文：[Physics-informed neural network for modelling the thermochemical curing process of composite-tool systems during manufacture](https://doi.org/10.1016/j.cma.2021.113959)
- 期刊：Computer Methods in Applied Mechanics and Engineering 384, 113959 (2021)
- 预印本：[arXiv:2011.13511](https://arxiv.org/abs/2011.13511)
- 作者官方代码：截至本次整理，论文与预印本未提供可确认的官方复现仓库
- 本仓库状态：`未开始`
- 本仓库分类：`支持论文／物理建模（非主动学习）`

## 为什么收入本仓库

论文用两个解耦网络求解热传导与树脂固化动力学的耦合方程，并处理复合材料—模具界面的物性不连续。它与粘合剂或树脂固化过程中的温度、固化度和工艺条件较接近。

但它**不是主动学习论文**。PINN 在这里是物理方程求解器或快速代理模型；只有外接采集函数，并让新实验结果回填重训后，才可能成为主动学习系统的一部分。

## 模型结构

| 模块 | 内容 |
|---|---|
| 输入 | 时间、空间位置、边界与工艺条件 |
| 输出 | 温度场、固化度等状态 |
| 物理约束 | 热传导 PDE、固化动力学 ODE、初边值和界面条件 |
| 训练信号 | 方程残差、边界/初始条件误差及可能的数据误差 |
| 主动学习采集函数 | 原论文没有 |

## 复现资产与缺口

论文提供控制方程、网络设计、顺序训练、自适应损失权重和多个案例，但没有可直接运行的官方代码、固定环境和完整数据。

这意味着本项目只能进行**论文重实现**，不能声称“运行作者代码完成忠实复现”。复现难度为**高**。

## 重实现步骤

1. 整理热传导方程、固化动力学及所有初始、边界和界面条件。
2. 用有限差分或现成求解器建立参考解。
3. 实现温度网络和固化度网络，以及每一项物理残差。
4. 按论文训练顺序加入自适应损失权重。
5. 复现不同厚度与边界条件案例。
6. 比较温度、固化度误差和推理速度。
7. 若未来接主动学习，必须另行定义候选实验条件、不确定性与采集函数。

## 对本项目的价值

这是与固化过程最接近的 PINN 支线，可用于构造物理特征、快速 Oracle 或多保真标签；它不能代替主动学习的选样算法。
