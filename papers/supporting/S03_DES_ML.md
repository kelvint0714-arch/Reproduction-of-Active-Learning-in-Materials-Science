# S03｜深共熔溶剂机器学习：监督学习与候选生成案例

## 论文与资源

- 论文：[Machine learning models accelerate deep eutectic solvent discovery for the recycling of lithium-ion battery cathodes](https://doi.org/10.1039/D4GC01418A)
- 期刊：Green Chemistry 26, 7857–7868 (2024)
- 作者仓库：[wenbomu/ML-accelerate-deep-eutectic-solvent-discovery](https://github.com/wenbomu/ML-accelerate-deep-eutectic-solvent-discovery)
- 本仓库状态：`已评估，暂不作为主动学习复现`

## 这篇论文做了什么

论文组合了：

- XGBoost、随机森林、SVR 和 ANN 进行性能预测；
- SHAP 解释模型；
- CGAN 生成理想化分子指纹；
- 相似度搜索寻找候选深共熔溶剂；
- 对部分候选进行实验验证。

它展示了一个完整的材料机器学习应用，但**不是主动学习**。

## 为什么不是主动学习

论文流程中没有明确的：

- 已标注集与未标注候选池；
- 基于不确定性的采集函数；
- 每轮选择下一批实验；
- 实验结果回填后重新训练的循环。

CGAN 生成候选不等于主动学习。它可以成为主动学习系统的**候选生成模块**，但不能替代选样闭环。

## 算法位置

| 算法 | 在论文中的作用 | 若接入主动学习可放在哪里 |
|---|---|---|
| XGBoost / RF / SVR / ANN | 监督学习预测 | 代理模型 |
| SHAP | 解释预测 | 分析模块，不负责选样 |
| CGAN | 生成理想化指纹 | 候选池生成 |
| 相似度搜索 | 将生成指纹映射到可用分子 | 候选筛选 |
| 实验验证 | 检查候选 | Oracle；原文未形成循环 |

## 公开资产与缺口

公开仓库包含 XGBoost、ANN、CGAN 和 SHAP 相关源码，但缺少关键 CSV、训练模型、固定环境和完整运行顺序，部分代码还有硬编码路径。

因此：

- 方法重实现难度为**中等**；
- 根据公开仓库精确复现难度为**高**；
- 未获得原始数据前，不应宣称重现论文数值结果。

## 可执行的复现步骤

1. 先确认能否从作者或补充材料获得原始数据。
2. 固定描述符、Morgan 指纹、归一化和数据划分。
3. 在相同划分下复现 SVR、RF、ANN 和 XGBoost 基线。
4. 复现 SHAP 分析，并核对特征含义。
5. 复现 CGAN 指纹生成与相似度筛选。
6. 单独构造主动学习候选池和回填循环，不把扩展结果写成原论文方法。

## 对本项目的价值

适合学习数据结构、传统机器学习、神经网络、解释和候选生成；只能作为应用参考，不能作为主动学习核心论文。
