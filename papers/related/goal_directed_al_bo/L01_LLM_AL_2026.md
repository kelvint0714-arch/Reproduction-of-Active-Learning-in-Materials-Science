# L01｜LLM-AL：免任务训练的材料顺序推荐

## 这篇论文真正做了什么

LLM-AL 不为每个数据集重新拟合一个任务专用代理模型，而是把少量已有实验和候选描述放进提示，让预训练 LLM 提出下一实验条件，再把生成建议映射回离散候选池。论文比较两种提示格式，并与 GPR、随机森林、XGBoost、贝叶斯神经网络和随机采样比较。

四个任务都是目标导向的：

| 数据集 | 目标 |
|---|---|
| Matbench steels | 最大化屈服强度 |
| P3HT/CNT | 最大化电导率 |
| Perovskite | 最小化不稳定性指标 |
| Membrane | 最大化弹性模量 |

完整流程使用 Claude 3.7 Sonnet 生成建议，并用 Cohere Rerank-v3.5 把建议映射到候选池。传统模型基线使用基于均值和不确定性的 UCB 类策略。

## 为什么不归入 `AL-core`

作者称其为 pool-based active learning，但实验以“多少轮找到最优候选”为主，达到池中最优值后停止。这与本仓库的 BO/目标优化定义更接近。

因此标记为：

```text
LLM 驱动的目标导向 AL / 离散池顺序优化
```

“Training-free”只表示不为当前任务训练新的监督代理模型，不表示没有模型推理、API、费用、提示设计或外部重排序依赖。论文也没有使用所谓“逻辑图谱”作为核心算法。

## 数据和算法映射

| 模块 | 论文中的内容 |
|---|---|
| 输入 | 数值参数格式或扩展文本描述 |
| 已观测上下文 | 少量候选及其目标值 |
| 推荐器 | 预训练 LLM |
| 池映射 | 外部 reranker 将文本建议映射到可选候选 |
| 对照代理模型 | GPR、RF、XGBoost、BNN |
| 目标 | 用更少迭代找到池中的最大/最小目标 |
| 主要指标 | 到达最优候选所需实验次数与轨迹稳定性 |

## 公开资产与复现边界

官方仓库提供四个数据集、选择轨迹和分析 notebook，可复核论文图表与已保存结果。

完整重新生成轨迹仍面临：

- 商业 LLM 和 reranker API 的费用与权限；
- 云端模型版本漂移；
- 温度设置之外的非确定性；
- 提示、候选排序和服务端实现变化；
- 当前仓库页面未显示独立代码许可证，复用前需再次核验授权。

因此它适合做**前沿高级案例**，不适合作为学习 GP、RF 或主动学习循环的第一篇论文。

## 最小复现建议

1. 先离线读取作者保存的轨迹，不调用商业 API。
2. 核对四个任务的目标方向和停止条件。
3. 重画“迭代数—best-so-far”曲线。
4. 用相同初始点重跑 Random、GPR-UCB 和 RF-UCB。
5. 将提示、模型标识、API 日期、温度和全部原始响应写入日志。
6. 最后才尝试一个小数据集的 LLM 在线复现，并估算成本。

## 对本项目的价值

它展示了一种无需为每个新材料表格重新训练代理模型的推荐方式，可作为未来的人机协作界面和高级基线。但当前研究主线仍应先掌握可解释、可离线复现的 RF/GP/GNN 主动学习与 BO，再评估 LLM 是否真正带来超越强基线的增益。
