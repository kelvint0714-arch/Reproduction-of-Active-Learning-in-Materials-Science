## 这篇论文做了什么

论文研究部分贝叶斯神经网络（PBNN）：网络的一部分保持确定性，另一部分使用概率权重。这样既能利用神经网络表示能力，又能得到主动学习需要的后验预测分布。

论文还讨论迁移学习：先用理论、模拟或相关任务训练，再把学到的表示或权重作为小样本实验任务的先验。

论文实验涉及 FreeSolv、ESOL、NIMS Steel、HTEM 以及带隙迁移学习。它的主动学习目标主要是用更少标签改善整体预测，而不是直接寻找性能最大值；迁移到材料优化时还需接入 EI/UCB 等目标导向采集函数。

## 主动学习映射

| 模块 | 本论文中的内容 |
|---|---|
| 输入 | 材料/化学特征或预训练表示 |
| 代理模型 | 普通 NN、PBNN、FBNN，以及 GP/DKL 对照 |
| 预测 | 后验预测均值 |
| 不确定性 | 贝叶斯层采样产生的后验方差 |
| 采集 | 最大预测不确定性，优先改善整体模型 |
| Oracle | 公开材料/化学数据或模拟标签 |
| 迁移 | 用来源任务帮助小样本目标任务 |

普通神经网络本身不自动成为主动学习方法。关键是 PBNN 如何给出有意义的不确定性，以及采集函数怎样使用它。

## 公开资产与缺口

NeuroBayes 提供 PBNN/FBNN、示例和主动学习相关实现，适合直接核查论文方法。

需要固定和检查：

- 论文对应 release/commit；
- 哪些层被贝叶斯化；
- 后验采样方法、样本数和随机种子；
- 预训练权重如何转成先验；
- 计算量和硬件；
- 不确定性是否真正校准，而不只是数值更大。

当前可复现性为**高**，但贝叶斯推断计算量可能较大。

## 忠实复现步骤

1. 固定论文代码版本并运行最小 PBNN 回归示例。
2. 在同一划分上训练普通 NN、PBNN 和论文必要基线。
3. 保存每个样本的预测均值、标准差和真实误差。
4. 检查不确定性与误差相关性及覆盖率。
5. 运行论文主动学习示例，固定初始点和总预算。
6. 比较 Random、GP、普通 NN、PBNN/FBNN 的发现效果与耗时。
7. 单独复现预训练/迁移设置，不与从零训练结果混在一起。

## 学习时必须回答

- 为什么只把部分层概率化可能已经足够？
- 认知不确定性和观测噪声有什么区别？
- 预测标准差大是否一定表示模型会犯错？
- 迁移先验何时帮助，何时会产生负迁移？
- PBNN 的成本与 GP、深度集成相比如何？

## 对本项目的价值

P04 是“传统神经网络如何进入主动学习”的核心论文。它适合小数据和已有相关模拟/公开数据的场景，也为后续 GNN 集成或 DKL 提供不确定性比较基线。
