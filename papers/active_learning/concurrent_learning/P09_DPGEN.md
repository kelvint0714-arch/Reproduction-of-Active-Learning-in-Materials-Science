# P09｜DP-GEN：神经网络模型分歧驱动的并发学习

## 论文与资源

- 论文：[DP-GEN: A concurrent learning platform for the generation of reliable deep learning based potential energy models](https://doi.org/10.1016/j.cpc.2020.107206)
- 期刊：Computer Physics Communications 253, 107206 (2020)
- 作者仓库：[deepmodeling/dpgen](https://github.com/deepmodeling/dpgen)
- 本仓库状态：`未开始`
- 本仓库分类：`并发学习（主动学习分支）`

## 这篇论文做了什么

DP-GEN 为深度势能模型循环生成训练数据：

```text
少量已标注原子构型
  → 用不同随机初始化训练多个 Deep Potential 模型
  → 在分子动力学中探索新构型
  → 用模型预测分歧识别“不确定”构型
  → 用 DFT 标注
  → 回填并重新训练
```

它属于主动/并发学习，但不是 GP + EI/UCB 形式的贝叶斯优化。这里的核心采集信号是多个神经网络之间的预测分歧。

## 算法在闭环中的位置

| 模块 | DP-GEN 中的内容 |
|---|---|
| 输入表示 | 原子种类与三维构型 |
| 代理模型 | Deep Potential 神经网络集成 |
| 不确定性近似 | 多个模型对能量/力的预测分歧 |
| 探索 | 分子动力学生成候选构型 |
| Oracle | DFT 计算能量、力和应力 |
| 输出 | 扩充后的势能训练集和可靠势模型 |

## 公开资产与缺口

公开仓库是成熟 Python 工程，包含文档、教程、示例、测试、环境配置和许可证，并可连接 DeePMD-kit、LAMMPS、VASP、CP2K、Quantum ESPRESSO 及集群调度器。

主要门槛：

- 需要分子动力学与第一性原理计算知识；
- 完整复现通常需要 HPC；
- 部分 DFT 软件涉及额外许可证；
- 它面向原子势，并不能直接接受粘合剂配方 Excel。

复现难度为**很高**。

## 忠实复现步骤

1. 先完成官方最小教程，不直接复现大型材料体系。
2. 安装 DP-GEN、DeePMD-kit 和可用的 MD/DFT 后端。
3. 准备少量带能量和力标签的初始构型。
4. 用不同随机初始化训练模型集成。
5. 运行短 MD 探索，按论文阈值划分可信、候选和失败构型。
6. 对候选构型做 DFT 标注，回填并重复。
7. 绘制模型分歧、误差、构型覆盖与计算成本曲线。

## 学习时必须回答

- 为什么模型分歧可以近似认知不确定性？
- 分歧阈值过高或过低会怎样？
- MD 负责生成候选，DFT 负责什么？
- 这种方法和“候选池中选配方”有哪些相同与不同？

## 对本项目的价值

可借鉴“神经网络集成分歧 → 不确定性 → 选样”的思想，但直接应用价值有限。它适合作为后期高级工程，而不是粘合剂表格数据的首个模型。
