# A04｜何时不确定性主动学习会失效：多类材料黑箱函数基准

## 论文信息

- **正式题名**：*Performance of uncertainty-based active learning for efficient approximation of black-box functions in materials science*
- **作者**：Ai Koizumi, Guillaume Deffrennes, Kei Terayama, Ryo Tamura
- **年份 / 期刊**：2024，*Scientific Reports* 14, 27019
- **DOI / 全文**：[10.1038/s41598-024-76800-4](https://doi.org/10.1038/s41598-024-76800-4)
- **开放全文备份**：[PMC11541781](https://pmc.ncbi.nlm.nih.gov/articles/PMC11541781/)

## 这篇论文解决什么问题

论文检验“不确定性最大就最值得标注”是否在材料回归中普遍成立。目标不是找最优材料，而是用少量标签准确近似整个材料输入—性质黑箱函数。

作者同时研究低维均匀空间和高维、离散、不平衡的材料描述符空间，得到一个很重要的负面结论：主动学习并不总比随机采样好，描述符维数和数据分布会显著影响结果。

## 主动学习要素

| 要素 | 论文中的设置 |
|---|---|
| **AL 目标** | 用更少标签提高整个黑箱函数的预测精度 |
| **输入** | 三元合金组成；无机材料的组成/结构描述符；小分子指纹；聚合物单体指纹 |
| **标签 / oracle** | 液相线温度、带隙、电子/晶格介电常数、吸收波长与强度、玻璃化转变温度 |
| **代理模型** | PHYSBO 中的 GPR 负责预测均值与不确定性；另用 GPR 或 Random Forest 检查预测精度 |
| **AL 采集策略** | US：最大预测标准差；TS-\(\mu\)：去除均值后的 Thompson 样本 |
| **对照方法** | Random；普通 TS 被明确作为贝叶斯优化对照 |
| **统计设置** | 多个任务使用 10 个初始点和 200 次独立重复 |

## 怎样评价

- 验证集 \(R^2\) 随迭代次数的变化；
- 200 次重复的均值和标准差；
- 前 100 步中 AL 与 Random 的平均 \(R^2\) 差：
  \[
  \langle\Delta R^2\rangle
  = \frac{1}{N_{\mathrm{step}}}
  \sum_i (R^2_{i,\mathrm{AL}}-R^2_{i,\mathrm{Random}})
  \]
- 描述符维数、初始标签数与 AL 收益的关系。

低维、均匀离散化的三元液相面上，US 明显有效；在高维且不平衡的小分子、聚合物和部分无机描述符上，US 可能与随机采样相当甚至更差。

## AL 还是 BO

**判定：主要实验是真正的主动学习；论文同时放入 BO 对照。**

- US 与 TS-\(\mu\) 只利用不确定性，目标是提高全局 \(R^2\)，属于 AL。
- 普通 TS 同时保留预测均值，目标偏向寻找高性质候选，论文明确把它称为 Bayesian optimization。

这篇论文最适合用来学习“采集函数相似，不代表研究目标相同”。

## 复现建议

- **难度**：中到高，主要障碍是论文整理数据没有完整公开。
- **最小任务**：
  1. 先选一个可公开取得的无机材料回归表；
  2. 用低维组成描述符和高维 Matminer 描述符各做一组；
  3. 固定测试集，比较 Random、US、TS 三条 \(R^2\) 曲线；
  4. 用至少 20 个种子先验证趋势；
  5. 计算前 100 轮的 \(\langle\Delta R^2\rangle\)，检查维数升高后 AL 优势是否减弱。
