# A03｜Benchmark-AL-Mat：材料小样本回归的主动学习基准

## 论文信息

- **正式题名**：*A comprehensive benchmark of active learning strategies with AutoML for small-sample regression in materials science*
- **作者**：Jinghou Bi, Yuanhao Xu, Felix Conrad, Hajo Wiemer, Steffen Ihlenfeldt
- **年份 / 期刊**：2025，*Scientific Reports* 15, 37167
- **DOI / 全文**：[10.1038/s41598-025-24613-4](https://doi.org/10.1038/s41598-025-24613-4)
- **代码与结果**：[bjhtud/Benchmark-AL-Mat](https://github.com/bjhtud/Benchmark-AL-Mat)

## 这篇论文解决什么问题

材料主动学习论文经常只在单一数据集和单一模型上展示结果，难以判断方法是否通用。这篇工作把 AutoML 作为每轮会重新选择模型与超参数的代理学习器，在 9 个小型材料配方数据集上系统比较 17 种主动学习策略和随机基线。

它尤其适合回答一个重要问题：主动学习是否真的比随机采样更好，以及优势出现在标注过程的哪个阶段。

## 主动学习要素

| 要素 | 论文中的设置 |
|---|---|
| **AL 目标** | 在固定标注预算下，提高材料性质回归模型的整体精度与数据效率 |
| **输入** | 混凝土、金属和复合材料的表格型配方、组成、工艺或结构参数 |
| **标签 / oracle** | 连续材料性能，如抗压强度、界面性能、铝合金力学性能等 |
| **代理模型** | Auto-sklearn；每轮在同一时间预算下重新搜索回归管线 |
| **采集策略** | 不确定性、EMCM、多样性、代表性及混合策略，共 17 种 |
| **对照方法** | Random sampling |
| **轮次设置** | 每轮批量增加 10 个标签；每种策略使用随机种子 30–49 做 20 次重复 |

论文比较的代表性策略包括 GP、QBC、RT-AL、QDD、GSx / GSy / iGS、RD 系列、MCDO、LL4AL、LCMD 等。正式论文口径是 **17 种 AL 策略＋Random**；仓库 README 的 “20+” 是对实现数量的概括，引用论文结果时不能混写。代理模型和策略覆盖 GP、树、委员会、MLP 与几何/聚类方法，因此不能用这篇论文支持“AL 底层都是 GP”。

它没有宣称某一种方法永远最好：早期小数据阶段混合策略更有优势，数据量增大后方法间差距会收窄。

## 怎样评价

- 测试集 MAE 与 \(R^2\)；
- MAE—标注次数曲线的 AUC；
- 达到最大 \(R^2\) 的 60%、70%、80%、90% 所需标签数；
- 相对于随机采样的标签数比和置信区间宽度比；
- 20 次重复实验的置信区间。

## 代码与数据核验

- **作者仓库**：[Benchmark-AL-Mat](https://github.com/bjhtud/Benchmark-AL-Mat)
- **数据状态**：论文说明 9 个数据集均为开放数据，并在正文表 2 给出各自来源；仓库直接展示/附带的示例数据不等于九个数据集都已打包，完整复现仍需按论文来源逐一取得并固定版本。
- **核验状态（2026-07-29）**：论文的 Data availability 和 Code availability 均指向上述作者仓库。完整基准会重复训练大量 AutoML 模型，公开不等于运行成本低。

## AL 还是 BO

**判定：真正的主动学习，不是贝叶斯优化。**

目标是更快降低测试误差，而不是找到性质最大或最小的单个候选。论文把随机采样作为基线，并在同一测试集上追踪整个学习曲线。

## 复现建议

- **难度**：中到高；算法代码易获得，但完整 AutoML 基准耗时较大。
- **最小任务**：
  1. 只选 UCI Concrete 一个数据集；
  2. 只比较 Random、Tree-based-R、RD-GS 三种策略；
  3. 保留固定测试集和每轮 10 个标签；
  4. 先把 AutoML 单轮时间预算调低并跑 5 个种子，确认流程；
  5. 正式复现时恢复论文时间预算和 20 个种子；
  6. 同时报告 \(R^2\) 曲线和达到目标 \(R^2\) 所需标签数。
