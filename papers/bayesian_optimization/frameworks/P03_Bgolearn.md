# P03｜Bgolearn：统一材料贝叶斯优化框架

## 论文与资源

- 论文：[Bgolearn: a unified Bayesian optimization framework for accelerating materials discovery](https://doi.org/10.1038/s41524-026-02226-3)
- 期刊：npj Computational Materials (2026)
- 主仓库：[Bin-Cao/Bgolearn](https://github.com/Bin-Cao/Bgolearn)
- 示例与数据：[Bgolearn/CodeDemo](https://github.com/Bgolearn/CodeDemo)
- 官方文档：[bgolearn.netlify.app](https://bgolearn.netlify.app/)
- 本仓库状态：`未开始`

## 这篇论文做了什么

Bgolearn 将材料贝叶斯优化常见组件封装成统一工具，使代理模型和采集函数可以替换。公开实现包含多种回归/分类模型、采集函数、示例数据、中文文档与安装方式。

它既适合复现论文，也适合作为以后统一接口的工程参考；但调用一个软件包得到推荐点，不等于提出了新算法。

论文的 TPMS 案例提供了一个可操作入口：四个几何参数作为输入，50 个已模拟结构作为初始数据，5000 个未测试结构作为候选池，目标是最大化弹性模量；每轮推荐 2 个结构并进行两轮验证。精确数据与模拟设置仍应从代码和补充材料核对。

## 贝叶斯优化映射

| 模块 | Bgolearn 中的内容 |
|---|---|
| 输入 | 表格型材料特征和候选池；TPMS 案例为四个几何参数 |
| 代理模型 | GP、SVM、RF、AdaBoost、MLP、梯度提升等 |
| 不确定性 | 取决于所选代理模型及框架实现 |
| 采集函数 | EI、AEI、EQI、REI、UCB、PoI、PES、KG 等 |
| Oracle | 公开数据、模拟或真实材料实验 |
| 输出 | 下一批候选及相应采集分数 |

不同模型输出不确定性的方式必须逐项检查，不能假设所有模型都具有 GP 后验。

## 公开资产与缺口

公开资源相对完整：

- 可安装 Python 包；
- 中文和英文说明；
- CodeDemo 与示例数据；
- 多模型、多任务和多采集函数接口。

需要核对：

- 论文对应的确切软件版本；
- 每种非 GP 模型的不确定性定义；
- 默认数据预处理和随机种子；
- 示例结果与论文图表的对应关系；
- 批量选择与约束如何实现。

当前可复现性为**高**，但精确论文复现仍需固定版本。

## 忠实复现步骤

1. 固定论文版本、PyPI 版本、主仓库和 CodeDemo commit。
2. 在独立环境运行官方单目标回归最小示例。
3. 保存输入 CSV、目标方向和推荐输出。
4. 用相同数据比较两个代理模型、三个采集函数。
5. 核对每个模型怎样产生均值和不确定性。
6. 用 Random 基线和多个随机种子重新评价。
7. 把框架输出转换为统一实验日志，而不直接修改原始示例。

## 学习时必须回答

- 为什么模型和采集函数应当解耦？
- RF/MLP 使用 EI 时，其概率预测来自哪里？
- 多种采集函数名字很多，哪些是真正适合当前目标和噪声的？
- 软件框架贡献与算法贡献有什么区别？

## 对本项目的价值

价值很高。P03 是较现代的工程基线，可帮助我们快速验证材料表格数据上的 BO 选样流程，并为统一实现提供接口设计参考。
