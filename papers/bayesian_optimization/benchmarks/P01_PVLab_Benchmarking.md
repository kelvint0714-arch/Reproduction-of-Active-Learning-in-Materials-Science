## 这篇论文做了什么

论文在多个真实实验材料数据集上回放贝叶斯优化，研究代理模型、采集函数、初始样本、批量大小和随机性怎样影响材料优化效率。完整数据在离线复现中充当 Oracle：模型每轮只能看到已选择候选的标签。

这篇论文是理解以下问题的基础：

- GP 与随机森林如何充当代理模型；
- 预测均值和不确定性如何交给采集函数；
- EI、PI、置信界和 Greedy 与 Random 有什么差别；
- 为什么一次成功轨迹不能代表算法稳定有效。

论文包含五类实验数据：

| 数据 | 输入 | 预测/优化目标 |
|---|---|---|
| Crossed-barrel | 几何参数 \(n,\theta,r,t\) | 最大化韧性 |
| AgNP | 多种反应物流量 | 最小化光谱损失 |
| AutoAM | 打印速度、延迟、偏移修正 | 最大化打印质量评分 |
| P3HT/CNT | 五种配方比例 | 最大化电导率 |
| Perovskite | Cs/FA/MA 组分比例 | 最小化不稳定性指标 |

## 贝叶斯优化映射

| 模块 | 本论文中的内容 |
|---|---|
| 输入/候选池 | 多个真实实验材料数据集中的候选及特征 |
| 目标 | 在有限查询预算内找到目标性质最优的材料 |
| 初始已标注集 | 论文实验通常从 2 个随机点开始，精确设置需按具体 Notebook 核对 |
| 代理模型 | GP、带 ARD 的 GP、RF 等 |
| 不确定性 | GP 后验；RF 使用集成预测分散程度 |
| 采集函数 | Random、Greedy、EI、PI、置信界等 |
| Oracle | 完整公开数据中的隐藏标签 |
| 评价 | 找到最优候选的速度、轨迹和重复实验统计 |

## 为什么先在 BO 路线复现它

P01 的材料问题真实，但闭环仍能在普通电脑上离线回放。它同时提供论文、代码、数据和 Notebook，适合先把“模型训练—预测—选样—揭示标签—重训”跑通。

复现难度为**中等**：公开资产较完整，但依赖较旧，可能需要兼容性修复。

## 公开资产与缺口

作者仓库包含多个材料数据集、GP/RF 相关 Notebook 和依赖说明。

需要核查：

- 论文对应的准确 commit 或 release；
- 每个 Notebook 与论文哪张图对应；
- 作者环境能否在 Apple Silicon 上原样安装；
- 随机种子、重复次数和部分默认超参数是否全部公开；
- RF 不确定性的具体实现。

在这些内容未核对前，不把 README 中的模型名称当成论文完整实验设置。

## 忠实复现步骤

1. 克隆作者仓库到本仓库外部，记录 commit、许可证和数据文件。
2. 选择一个仓库自带的小型材料数据集与最小 Notebook。
3. 在独立环境中运行作者原始配置，先不改算法。
4. 保存每轮候选、预测、采集分数和当前最优值。
5. 复现 Random 基线以及普通 GP、GP-ARD 或 RF 中至少一个方法。
6. 使用论文要求的多个随机种子，核对 Top 5% 命中率、提升/加速因子和优化轨迹。
7. 对照论文图表，记录一致、部分一致或无法重现。
8. 再将数据和方法接入本项目统一接口。

## 学习时必须回答

- 为什么离线复现时要隐藏未选候选的标签？

- 为什么至少要运行多个初始点和随机种子？

## P01 完成标准

- 一个真实数据集可以从零运行；
- Random、一个概率代理模型和一个采集函数均有结果；
- 记录 30 个以上随机种子或说明论文实际重复设置；
- 输出 best-so-far、regret 或 top-k 命中曲线；
- 环境、原始日志、依赖修复和复现偏差均可检查。

只有达到这些条件，才进入 P02。
