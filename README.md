# Reproduction of Active Learning in Materials Science

本仓库用于系统阅读、复现和比较**材料科学中的主动学习（Active Learning, AL）论文**。这里不是粘合剂专用模型，也不是把几个算法名称简单拼在一起；目标是先在公开数据和作者代码上复现成熟方法，再逐步形成可迁移到粘合剂或其他材料体系的通用算法框架。

## 当前研究问题

我们要回答四个问题：

1. 在小样本材料数据上，GP、随机森林、XGBoost、神经网络等代理模型分别适合什么情况？
2. 最大不确定性、UCB、EI、PI、Thompson Sampling 等采集函数，哪一种能用更少实验找到高性能材料？
3. GNN、部分贝叶斯神经网络（PBNN）和深核学习（DKL）怎样进入主动学习闭环？
4. PINN、结构化 GP 或其他物理先验，能否进一步降低真实实验需求？

## 最重要的关系

```text
材料表示/特征
├── 表格特征、分子指纹
└── GNN/神经网络学习的结构表示
                ↓
代理模型：GP / RF / XGBoost / MLP / GNN / DKL
                ↓
预测均值 μ(x) ＋ 不确定性 σ(x)
                ↓
主动学习采集函数：Uncertainty / UCB / EI / PI / TS
                ↓
下一批实验、模拟或数据库标签
                ↓
加入已标注集并重新训练
```

GNN、随机森林和神经网络本身通常不是主动学习算法。它们在闭环中充当**代理模型或特征提取器**；采集函数利用它们的预测和不确定性决定下一批样本。

## 每篇论文的复现原则

每篇论文分成两个阶段：

1. **忠实复现**：尽可能保持原始数据、划分、模型、采集函数、随机种子和评价指标。
2. **统一重实现**：把论文方法接入同一个接口，在相同数据预算和评价标准下重新比较。

不得把“运行作者代码”直接等同于“复现论文结论”。至少需要记录：

- 论文版本、DOI、代码提交或 release；
- 数据来源和标签含义；
- 初始已标注集如何选择；
- 候选池如何构成；
- 代理模型如何输出不确定性；
- 采集函数和批量大小；
- 停止条件、随机种子和重复次数；
- 预测指标与材料发现指标；
- 与论文结果的偏差及原因。

## 数据与版权

- 本仓库只保存我们自己的笔记、配置、实验日志和允许再分发的数据。
- 不直接上传受版权保护的论文 PDF；使用 DOI 或出版社链接。
- 不把论文图表、数据或代码的许可范围想当然，复现前先检查对应许可证。
- 与粘合剂相关的真实实验数据必须保留原始单位、测试标准、批次和来源，不能与公开演示数据混用。
