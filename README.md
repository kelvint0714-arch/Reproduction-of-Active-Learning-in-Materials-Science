# Reproduction of Active Learning in Materials Science

本仓库用于系统阅读、筛选和复现**材料科学中的主动学习（Active Learning, AL）**。研究目标是先在公开论文、公开数据和作者代码上复现成熟方法，再形成可迁移到粘合剂或其他材料体系的通用闭环。

> 重要纠偏：仓库不再把“主动学习”和“贝叶斯优化”混成一类。P01（PV-Lab）是贝叶斯优化基准，不是本仓库的第一篇主动学习复现。

## 先分清两个任务

| 任务 | 想解决的问题 | 常见采集方式 | 主要评价 |
|---|---|---|---|
| 主动学习（模型学习） | 用最少新标签学好整个结构—性质映射、相图或势能面 | 最大不确定性、QBC、代表性、多样性、core-set | MAE/RMSE、校准、达到目标误差所需标签数 |
| 贝叶斯优化（目标优化） | 用最少实验找到最大、最小或满足目标的候选 | EI、PI、UCB/LCB、TS、EHVI | best-so-far、regret、top-k 命中、找到目标所需实验数 |

两者可以共用 GP、RF、XGBoost、神经网络或 GNN，也可以出现在同一篇论文的不同阶段，但**优化目标和评价指标不能混写**。详细判据见 [主动学习与贝叶斯优化的边界](docs/04_主动学习与贝叶斯优化的边界.md)，公式与方向约定见 [查询策略与采集函数的数学结构](docs/05_查询策略与采集函数数学结构.md)。

## 算法在闭环中的位置

```text
材料表示
├── 表格特征、工艺条件、分子指纹
└── GNN / 神经网络学习的结构表示
                ↓
代理模型：GP / RF / XGBoost / MLP / GNN / DKL
                ↓
预测均值 μ(x) ＋ 不确定性 σ(x)
                ↓
查询策略
├── AL：不确定性 / QBC / 代表性 / 多样性
└── BO：EI / PI / UCB / TS / EHVI
                ↓
下一批实验、模拟或数据库标签
                ↓
加入已标注集并重新训练
```

GNN、随机森林和神经网络本身通常不是主动学习算法。它们在闭环中充当**表示器或代理模型**；查询策略才决定下一批获取哪些标签。

## 当前第一条复现路线

优先顺序按“概念明确、公开代码/数据完整、普通电脑可缩小复现”排序：

1. **NIST structure–property AL（2024）**：在固定微结构数据上比较 uncertainty、GSx、GSy、iGS；
2. **DAGS（2025）**：用合成数据跑通 Random、iGS、QBC、RT-AL、DAGS 的学习曲线；
3. **材料数据冗余/QBC（2023）**：理解 RF/XGBoost 不确定性和 committee disagreement；
4. **AutoML 材料 AL 基准（2025）**：在一个小型材料回归数据集上比较 17 种方法中的代表策略；
5. 再进入 GNN、PBNN、DKL、势函数并发学习和真实实验闭环。

## 粘合剂怎样进入项目

算法框架不依赖“粘合剂”这个名称。迁移到粘合剂时，更换的是：

- 输入：配方组成、树脂/固化剂结构、比例、固化和测试条件；
- Oracle：公开数据、模拟或化学组实验；
- 目标：强度、模量、Tg、耐久性等；
- 约束：可制备性、安全规则、比例和工艺窗口。

Pruksawan 等（2019）的环氧粘合剂论文应作为**作者所称 AL＋后续 BO 的应用案例**理解。严格看，它前半段按预测强度选择 top-5，更接近目标导向的 Greedy 自适应取样，而不是最大不确定性 AL；后半段才明确使用 EI 做 BO。它不能替代通用主动学习基准，但适合以后验证粘合剂迁移和比较不同选样目标。

## 论文准入与复现原则

每篇候选论文必须记录：

- 正式题名、DOI、发表年份和来源；
- 它实际优化的是全局模型误差、数据覆盖，还是性质极值；
- 输入、标签、代理模型、不确定性和查询策略；
- 代码、数据、许可证、运行入口及其核验状态；
- 最小可复现任务、所需算力和已知阻塞。

复现分两层：

1. **忠实复现**：尽量保持原始数据、划分、模型、采集策略、种子和指标；
2. **统一重实现**：在相同数据预算、初始点、批量大小和评价协议下公平比较。

不得把“作者提供了代码”写成“我们已经复现成功”；真正完成必须有固定版本、环境、命令、日志、结果和偏差说明。

## 数据与版权

- 仓库只保存自己的笔记、配置、实验日志和允许再分发的数据；
- 不上传受版权保护的论文 PDF，使用 DOI、出版社或公开归档链接；
- 真实实验数据保留原始单位、测试标准、批次、失败记录和来源；
- 所有论文、代码和数据链接以 [LITERATURE_WATCH](papers/LITERATURE_WATCH.md) 中的核验日期为准。
