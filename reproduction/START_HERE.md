# 从这里开始：第一次复现真正的材料主动学习

当前只开始 **A01：NIST 微结构—性质主动学习**。它的目标是用更少标签学好整个结构—性质映射，主要评价固定测试集 MAE，因此比 P01 贝叶斯优化更适合作为主动学习第一篇。

本轮不连接真实粘合剂实验，不同时安装十篇论文环境，也不声称“克隆代码”就是复现完成。

## 1. 先读论文卡和边界说明

依次阅读：

1. [A01 论文复现卡](../papers/active_learning/literature/A01_NIST_Structure_Property_AL_2024.md)；
2. [主动学习与贝叶斯优化的边界](../docs/04_主动学习与贝叶斯优化的边界.md)；
3. [查询策略与采集函数的数学结构](../docs/05_查询策略与采集函数数学结构.md)；
4. [统一主动学习流程](../docs/02_统一主动学习流程.md)；
5. 论文摘要、方法、实验设置、数据与代码可用性。

读完后先填写，不知道就写 `待确认`：

| 问题 | A01 的初始答案 |
|---|---|
| 输入 \(X\) 是什么？ | 二维/三维微结构的数值表示；第一轮只用二维弹性数据 |
| 标签 \(y\) 是什么？ | 预计算的有效刚度 \(C_{11}^{eff}\) |
| 代理模型是什么？ | Gaussian Process Regression |
| 不确定性怎样获得？ | GP 对未标注样本的预测方差 |
| 查询策略是什么？ | Random、最大方差、GSx、GSy、iGS |
| 离线 Oracle 是什么？ | 作者公开完整数据中被暂时隐藏的标签 |
| 怎样判断 AL 好不好？ | 固定测试集 MAE 随已标注样本数下降得是否更快 |
| 为什么不是 BO？ | 不寻找刚度最大值，而是学习整个结构—性质映射 |

## 2. 把作者仓库放在本仓库之外

在本仓库根目录执行：

```bash
mkdir -p ../upstream
git clone https://github.com/usnistgov/active-learning.git ../upstream/A01-NIST-active-learning
cd ../upstream/A01-NIST-active-learning
git rev-parse HEAD
git remote -v
```

把 `git rev-parse HEAD` 的输出记录到实验日志。不要把整个上游仓库复制进本仓库，也不要先改作者代码。

## 3. 只检查来源和入口

在上游仓库中执行：

```bash
git status --short
find . -maxdepth 2 -type f | sort
```

记录：

- README 指定的运行入口；
- 二维弹性数据文件名及每个数组的含义；
- requirements、environment 或安装说明；
- 原始代码使用的 Python 与核心依赖；
- 论文对应的分支、tag 或 commit；
- 输出图和指标由哪个脚本产生。

仓库结构或文件名与论文卡不一致时，以当前锁定的 commit 为准，并在日志写明差异。

## 4. 建立独立环境

优先严格跟随作者仓库的环境文件。作者没有固定环境时，再建立最小环境；不要未经检查直接把所有包升级到最新版。

环境命名建议：

```bash
conda create -n al-a01-nist python=<作者代码兼容版本>
conda activate al-a01-nist
python --version
```

`<作者代码兼容版本>` 必须先从上游代码和依赖中确认，不能照抄一个猜测版本。

## 5. 第一轮只跑一个最小闭环

目标链条：

```text
读取二维弹性数据
→ 固定训练池与测试集
→ 选择少量初始已标注样本
→ 训练 GP
→ 预测未标注池均值与方差
→ 选择一个新样本
→ 从完整数据揭示标签
→ 加入训练集并重训
→ 记录测试 MAE
```

先运行作者最小入口。若作者代码一次执行很多方法或数据集，第一轮只缩小**运行范围**，不要改算法公式。

## 6. 最低比较实验

至少比较：

- Random；
- GP 最大预测方差；
- iGS。

公平条件：

- 同一训练池和测试集；
- 同一初始已标注点；
- 同一总标签预算；
- 每轮相同 batch size；
- 先 5 个随机种子做 smoke test，正式核对再扩展；
- 横轴统一为已获得标签总数，纵轴统一为测试 MAE。

## 7. 记录，而不是只截图

从 [实验日志模板](templates/experiment_log_template.md) 建立日志，至少保存：

- 日期、机器、操作系统；
- 论文 DOI、代码 commit、数据文件校验信息；
- 环境导出；
- 完整命令和参数；
- 随机种子；
- 原始 stdout/stderr；
- 每轮标签数、测试 MAE、选中样本编号；
- 失败、修改和偏差原因。

## 9. 什么时候进入 A02

满足以下条件后再做 DAGS：

- 能逐步解释 AL 循环的数据如何移动；
- 能解释 GP 方差为什么可作为查询信号；
- 所有结果可以从命令和日志重新生成；
- 已锁定代码、数据和环境版本；
- 没有把固定公开数据的离线查询写成真实实验；
- 已写清结果是否支持论文趋势。
