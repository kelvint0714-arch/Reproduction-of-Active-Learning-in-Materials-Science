# 论文复现检查表

每开始一篇论文，复制本检查表到对应实验目录并逐项完成。

## 1. 来源锁定

- [ ] 记录论文标题、作者、年份、期刊和 DOI
- [ ] 记录论文版本：正式版、预印本或补充材料
- [ ] 记录代码仓库 URL、branch、tag、release 和 commit SHA
- [ ] 检查代码与数据许可证
- [ ] 记录数据下载地址、版本、哈希或日期

## 2. 问题定义

- [ ] 输入 \(X\) 是什么
- [ ] 标签 \(y\) 是什么、单位是什么
- [ ] 是最大化、最小化还是学习全局模型
- [ ] 候选池是否固定
- [ ] Oracle 是数据库、模拟还是实验

## 3. 主动学习闭环

- [ ] 初始已标注样本数量和选择方式
- [ ] 代理模型
- [ ] 特征/表示方法
- [ ] 不确定性方法
- [ ] 采集函数
- [ ] batch size
- [ ] 每轮是否重新训练
- [ ] 总标签预算或停止条件

## 4. 实验设计

- [ ] 训练/验证/测试或候选池划分
- [ ] 防止相似材料、同一来源或同系列泄漏
- [ ] 随机种子
- [ ] 独立重复次数
- [ ] Random、Greedy 等必要基线
- [ ] 超参数选择没有偷看最终测试结果

## 5. 评价指标

- [ ] MAE、RMSE、\(R^2\) 等预测指标
- [ ] 不确定性校准
- [ ] best-so-far
- [ ] simple regret
- [ ] top-k / top-percent 命中
- [ ] 达到目标所需标签数
- [ ] 均值、标准差或置信区间

## 6. 结果核对

- [ ] 先运行作者原始代码
- [ ] 保存原始日志和环境
- [ ] 对照论文图表或表格
- [ ] 记录无法重现的数值
- [ ] 区分代码错误、环境差异、随机波动和缺失数据
- [ ] 未经证据不修改作者流程

## 7. 统一重实现

- [ ] 将数据适配到统一 schema
- [ ] 将模型适配到统一 `fit/predict` 接口
- [ ] 将采集函数与模型解耦
- [ ] 与其他方法使用相同初始点和预算
- [ ] 完成至少一个消融实验
- [ ] 记录与忠实复现的所有差异

## 8. 交付

- [ ] `README.md`：如何运行
- [ ] 环境文件
- [ ] 配置文件
- [ ] 固定随机种子
- [ ] 原始结果与处理后结果分开
- [ ] 图表可以从原始日志重新生成
- [ ] 写明成功、部分成功或阻塞
