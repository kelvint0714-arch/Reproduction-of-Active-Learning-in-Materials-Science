# 查询策略与采集函数的数学结构

## 先记住：公式服从任务目标

查询策略回答“下一次给哪个候选获取真实标签”。同一个代理模型可以连接不同策略：

```text
GP / RF / GNN 给出预测与不确定性
          ↓
AL：选择最能改善全局模型的点
BO：选择最可能改善当前最优值的点
```

高斯过程（GP）能自然给出后验均值 \(\mu(x)\) 和标准差 \(\sigma(x)\)，所以在材料 BO 中很常见，但它不是主动学习或贝叶斯优化的必需底层。RF 树间方差、Bootstrap、模型委员会、深度集成、MC Dropout、BNN 等也可以估计不确定性。

## 统一符号

| 符号 | 含义 |
|---|---|
| \(x\) | 一个未测试候选材料或实验条件 |
| \(\mu(x)\) | 模型对 \(x\) 的预测均值 |
| \(\sigma(x)\) | 模型对 \(x\) 的预测标准差 |
| \(f^+\) | 最大化问题中当前已观测的最好目标值 |
| \(f^-\) | 最小化问题中当前已观测的最好目标值 |
| \(\xi\) | EI/PI 中鼓励探索的非负参数 |
| \(\kappa\) | UCB/LCB 中不确定性的权重 |
| \(\Phi\)、\(\phi\) | 标准正态分布的 CDF 和 PDF |

这些公式默认代理模型的预测分布近似正态。若不确定性来自树模型或神经网络集成，必须检查相应实现怎样构造预测分布，不能把树间标准差自动当作严格的 GP 后验。

## 主动学习：为了学好整个模型

### 1. 回归最大不确定性

\[
a_{\mathrm{US}}(x)=\sigma(x)
\]

选择 \(a_{\mathrm{US}}\) 最大的候选。它不关心预测值是高还是低，只关心模型最没把握的位置。

局限：可能反复选择离群点或低密度区域，所以常与代表性、密度或多样性结合。

### 2. 分类熵

若模型给出 \(K\) 个类别概率 \(p(y=k\mid x)\)，则：

\[
H(x)=-\sum_{k=1}^{K}p(y=k\mid x)\log p(y=k\mid x)
\]

类别概率越接近，熵越大，说明分类器越不确定。二分类中 \(p\approx 0.5\) 的候选通常靠近当前决策边界。

### 3. 模型委员会分歧（QBC）

设 \(M\) 个模型对同一个候选的预测为 \(\hat y_1(x),\ldots,\hat y_M(x)\)：

\[
\bar y(x)=\frac{1}{M}\sum_{m=1}^{M}\hat y_m(x)
\]

\[
a_{\mathrm{QBC}}(x)=\frac{1}{M-1}\sum_{m=1}^{M}
\left(\hat y_m(x)-\bar y(x)\right)^2
\]

模型分歧越大，说明当前训练数据不足以让不同模型达成一致。委员会可由不同算法构成，也可由同一算法的不同 Bootstrap 样本或随机初始化构成。

### 4. 代表性和多样性

最简单的输入空间最远点策略为：

\[
a_{\mathrm{GSx}}(x)=\min_{x_i\in L} d(x,x_i)
\]

其中 \(L\) 是已标注集，\(d\) 是距离。选择离已标注集最远的候选可以提高覆盖，但距离必须与特征缩放和材料表示匹配。

批量选择时还要避免一批候选彼此过于相似，可以在不确定性得分之外加入候选间距离、聚类或 core-set 约束。

## 贝叶斯优化：为了更快找到最优候选

### 1. UCB 与 LCB

最大化目标：

\[
\mathrm{UCB}(x)=\mu(x)+\kappa\sigma(x)
\]

最小化目标：

\[
\mathrm{LCB}(x)=\mu(x)-\kappa\sigma(x)
\]

\(\mu\) 对应利用当前高性能区域，\(\sigma\) 对应探索未知区域。增大 \(\kappa\) 会提高探索权重。

### 2. 提升概率（PI）

最大化问题定义：

\[
Z(x)=\frac{\mu(x)-f^+-\xi}{\sigma(x)}
\]

\[
\mathrm{PI}(x)=\Phi(Z(x))
\]

PI 只关心“超过当前最好值的概率”，不考虑超过多少，因此可能过度利用当前最好区域。

### 3. 期望提升（EI）

最大化问题中的随机提升为：

\[
I(x)=\max(0, f(x)-f^+-\xi)
\]

若预测近似正态且 \(\sigma(x)>0\)，其期望为：

\[
\mathrm{EI}(x)=
\left(\mu(x)-f^+-\xi\right)\Phi(Z)
+\sigma(x)\phi(Z)
\]

其中：

\[
Z=\frac{\mu(x)-f^+-\xi}{\sigma(x)}
\]

若 \(\sigma(x)=0\)，则令 \(\mathrm{EI}(x)=0\)。

第一项偏向预测值已经较好的候选，第二项奖励不确定性较大的候选，因此 EI 同时平衡利用和探索。

最小化问题不能直接照抄最大化公式。定义：

\[
Z_{\min}=\frac{f^- - \mu(x)-\xi}{\sigma(x)}
\]

\[
\mathrm{EI}_{\min}(x)=
\left(f^- - \mu(x)-\xi\right)\Phi(Z_{\min})
+\sigma(x)\phi(Z_{\min})
\]

实现前必须明确目标方向，否则会稳定地推荐“最差”候选。

### 4. 多目标 EHVI

多目标优化没有单一的最好数值，而是形成帕累托前沿。超体积衡量当前非支配解相对于参考点覆盖的目标空间大小，EHVI 选择**期望超体积增量**最大的候选。

使用 EHVI 前必须明确：

- 每个目标是最大化还是最小化；
- 参考点；
- 目标缩放；
- 约束和不可行实验；
- 一次推荐一个还是一批。

只要主要目标是推进帕累托前沿，它仍属于多目标 BO，不会因为使用了“不确定性”就自动变成模型学习型 AL。

## 策略与指标必须成对

| 目标 | 合理策略示例 | 主要指标 |
|---|---|---|
| 降低全局回归误差 | Uncertainty、QBC、GSx/iGS、密度/代表性 | MAE、RMSE、\(R^2\)、校准、标签效率 |
| 学好分类边界 | Entropy、Margin、Least Confidence、QBC | F1、balanced accuracy、边界误差 |
| 找最大/最小值 | Greedy、PI、EI、UCB/LCB、TS | best-so-far、regret、成功率 |
| 找多目标折中 | Pareto、EHVI、多目标 TS | hypervolume、Pareto 命中、实验预算 |

## 实现时最容易犯的错误

1. 最大化和最小化的符号写反。
2. 把方差 \(\sigma^2\) 当成标准差 \(\sigma\)。
3. 对特征或目标做了标准化，却用原单位的 \(f^+\) 计算 EI。
4. 只跑一个初始集和一个随机种子。
5. 批量推荐时直接取单点得分前 \(k\) 名，导致候选彼此重复。
6. 把 RF 树间方差、MC Dropout 或 LLM 自信度称为已校准后验，却没有检验覆盖率。
7. 用 EI/UCB 找到一个高性能点后，反过来声称整个预测模型已经准确。

## 当前学习顺序

```text
先手算一个一维例子
→ 用 NumPy/SciPy 实现 US、UCB、PI、EI
→ 与成熟库结果逐点对照
→ 接入一个固定公开候选池
→ 比较 Random、AL 和 BO 的不同学习/发现曲线
```

现阶段优先使用 Python 验证公式。只有在公式、边界条件和单元测试都稳定后，才考虑用 C/C++ 重写性能关键部分。
