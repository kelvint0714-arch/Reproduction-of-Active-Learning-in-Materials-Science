# 算法与主动学习的关系

## 一句话结论

主动学习是一套**决定下一次获取哪个标签的流程**。GP、随机森林、XGBoost、MLP、GNN 和 PINN 通常位于流程内部，负责表示材料、预测性能或估计不确定性。

## 五个模块

| 模块 | 回答的问题 | 常见方法 |
|---|---|---|
| 材料表示 | 怎样把材料变成模型能读取的数字？ | 组成特征、工艺特征、ECFP、描述符、GNN embedding |
| 代理模型 | 如果做实验，性能大约是多少？ | GP、RF、XGBoost、MLP、GNN、DKL |
| 不确定性 | 模型对预测有多大把握？ | GP 方差、RF 树间方差、深度集成、MC Dropout、BNN/PBNN |
| 采集函数 | 下一批应该测谁？ | Uncertainty、UCB、EI、PI、TS、QBC |
| Oracle | 谁提供真实标签？ | 已知公开数据、DFT/MD 模拟、真实化学实验 |

## 随机森林在哪里使用

随机森林适合已经整理成表格的材料数据，例如组成、比例、温度、时间和物理描述符。主动学习每轮会：

1. 用当前已标注样本训练 RF；
2. 让每棵树预测所有未标注候选；
3. 用树预测的均值作为性能预测；
4. 用树之间的标准差近似模型不确定性；
5. 让采集函数选择下一批候选。

因此可以形成 `RF + Uncertainty`、`RF + UCB`、`RF + EI` 等实验组。

## GNN 在哪里使用

当候选具有 SMILES、分子图、晶体结构或其他图结构时，GNN 可以：

1. 直接从结构预测目标性质；
2. 输出一个结构 embedding，再交给 GP、RF 或其他模型；
3. 用多个 GNN 的预测分歧估计不确定性；
4. 让 UCB、EI 等采集函数根据预测与不确定性选样。

典型组合：

```text
分子图 → GNN → 性能预测与集成不确定性 → UCB/EI → 下一批分子
```

或：

```text
分子图 → GNN embedding → GP → 均值与方差 → UCB/EI
```

如果只有几十条表格数据且没有可靠结构，不能为了使用 GNN 强行构图。此时优先使用分子指纹或人工描述符配合 GP/RF。

## 神经网络怎样进入主动学习

普通神经网络只给一个点预测，不能自动给出可靠的不确定性。常见解决办法：

- 多个不同初始化的神经网络组成深度集成；
- MC Dropout；
- 贝叶斯神经网络或部分贝叶斯神经网络；
- DKL：神经网络提取特征，GP 给出概率预测。

本仓库重点复现 PBNN 和 DKL 两条路线。

## PINN 在哪里使用

PINN 只有在存在可信 ODE/PDE、边界条件和物理参数时才成立。它可以：

- 作为固化、传热、扩散或力学过程的代理模型；
- 产生固化度、峰值温度等物理特征，再交给材料性能模型；
- 在具有不确定性估计时，作为主动学习的代理模型之一。

PINN 的 PDE 配点自适应采样与“选择下一种材料做实验”不是同一个问题，必须分开评价。

## 我们最终比较什么

统一主动学习循环不变，只替换内部模块：

```text
GP + UCB
RF + UCB
XGBoost ensemble + UCB
PBNN + UCB
GNN ensemble + UCB
GNN/DNN + GP（DKL）+ UCB
物理先验模型 + UCB
```

这样才能回答：在相同实验预算下，哪种代理模型和采集函数更适合小样本材料发现。
