# 主动学习与贝叶斯优化的边界

## 一句话判断

- 如果下一点是为了**让模型在整个候选空间更准确、更可靠**，主任务是主动学习（AL）。
- 如果下一点是为了**尽快找到最高、最低或满足目标的候选**，主任务是贝叶斯优化（BO）。

不要只看论文标题、作者用词或采集函数名称，要看它真正优化的目标和最后报告的指标。

## 判定表

| 检查项 | 主动学习 | 贝叶斯优化 |
|---|---|---|
| 核心目标 | 学好函数、类别边界、相图或势能面 | 找到目标函数极值或 Pareto 前沿 |
| 典型问题 | “标注谁最能减少整体误差？” | “实验谁最可能改进当前最优值？” |
| 典型策略 | 最大不确定性、QBC、core-set、代表性、多样性 | EI、PI、UCB/LCB、TS、EHVI |
| 主要指标 | 测试 MAE/RMSE、F1、校准、标签效率 | best-so-far、regret、top-k、成功率 |
| 是否需要固定测试集 | 通常需要 | 不一定，重点常在发现轨迹 |
| 终止条件 | 预测/分类达到目标精度或预算耗尽 | 找到目标候选或预算耗尽 |

采集函数不是绝对判据。例如 UCB 既可被某些作者称为主动学习策略，也常用于 BO。必须结合目标、符号方向和评价指标判断。

## 三类容易混淆的论文

### 1. 标题写主动学习，实质是 BO

如果论文用 EI/UCB 反复选择预测最优或潜在改进最大的材料，并以 regret、最大性能或 top-k 命中评价，应该归入 BO，即使作者把整个闭环称为 active learning。

本仓库中的 P01、P02、P03 和 P06 主要属于这一类。

### 2. 一篇论文同时包含 AL 和 BO

例如：

```text
阶段 A：补充最有信息的实验，降低全局预测误差  → AL
阶段 B：用已经训练好的模型寻找最高性能候选    → BO
```

环氧粘合剂论文 Pruksawan et al.（2019）表面上是这种两阶段结构，但还要再严格一步：作者称前半段为 AL，实际却按预测强度选择 top-5，更接近 Greedy exploitation；后半段明确使用 EI 做 BO。复现时应分别报告：

- 作者所称 AL/Greedy 阶段的学习曲线、验证误差和新增标签数；
- BO 阶段的 best-so-far、推荐配方和实验验证。

### 3. 真实闭环平台不等于主动学习算法

自动化设备、数据管线和实验编排平台可以接入 AL、BO、专家规则或随机策略。平台论文必须单列，不能因为存在“模型推荐下一次实验”就自动归为 AL 核心算法。

## 对每篇新论文的五问

1. 每轮到底选择哪个样本，选择公式是什么？
2. 选择该样本是为了减小哪里、哪一种误差，还是为了提高当前最优值？
3. 最终横轴是标签/实验预算吗？
4. 纵轴是测试误差/覆盖率，还是 best-so-far/regret？
5. 随机基线是否在相同初始点、批量大小和预算下比较？

回答不清楚时先标记为“待分类”，不要强行纳入主动学习主线。

## 本仓库的收录标签

| 标签 | 含义 |
|---|---|
| `AL-core` | 明确以模型精度、数据覆盖、类别边界、相图或势能面学习为目标 |
| `AL-closed-loop` | 真实实验/模拟闭环中的信息型采样 |
| `AL-concurrent` | 势函数或模拟中的并发/在线选样 |
| `BO` | 单目标或多目标性质优化 |
| `AL+BO hybrid` | 两个目标在论文中均存在，且可以拆分 |
| `platform` | 提供闭环架构，但不限定查询算法 |
| `supporting` | PINN、普通监督学习、生成模型等支持模块 |

## 统一报告规则

如果目标是模型学习，至少报告：

- 固定测试集上的 MAE/RMSE/\(R^2\) 或分类指标；
- 不确定性校准（若方法依赖不确定性）；
- 性能随已标注样本数变化的学习曲线；
- 与 Random 的多随机种子比较。

如果目标是优化，至少报告：

- best-so-far 或 simple regret；
- 找到 top 1% / 5% 候选所需的实验数；
- 多随机种子的成功率和置信区间。

如果两者都有，两套指标都要保留，不能用一个高 \(R^2\) 代替材料发现结论，也不能用找到一个高性能候选证明全局模型已经学好。
