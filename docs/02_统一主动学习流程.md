# 统一主动学习流程

本文件定义所有论文复现都要映射到的统一闭环。不同论文可以使用不同数据、代理模型和采集函数，但必须明确每一步对应什么。

## 1. 明确研究目标

先区分两个目标，并在实验标题中明确写 `AL` 或 `BO`：

- **主动学习/模型学习**：用尽量少的标签降低整个候选空间的预测误差；
- **贝叶斯优化/材料优化**：用尽量少的实验找到目标性能最高、最低或满足约束的材料。

两者都需要时，报告必须同时给出预测指标和发现指标，不能只给 \(R^2\)。

## 2. 建立候选池

候选池中每一行必须对应一个可执行的实验、模拟或数据库查询。

最低字段：

| 字段 | 含义 |
|---|---|
| `candidate_id` | 永久且唯一的候选编号 |
| 输入特征 | 组成、结构、比例、工艺、测试条件等 |
| `label_status` | `measured`、`unmeasured`、`failed` |
| 目标列 | 离线复现时存在但对模型隐藏；真实实验时为空 |
| 来源 | 数据库、论文、模拟或实验批次 |

候选池不是随意生成的数值集合。真实实验前必须由材料组确认候选是否可制备、是否安全、组成是否满足约束。

## 3. 构造初始已标注集

常见方式：

- 论文指定的随机初始点；
- Maximin、聚类中心或拉丁超立方等空间覆盖方法；
- 专家选择；
- 已有历史实验。

复现论文时先服从原文；统一比较时再使用相同的初始点和随机种子。

## 4. 训练代理模型

代理模型只允许读取已标注集：

```python
model.fit(X_labeled, y_labeled)
```

然后预测未标注池：

```python
mean, uncertainty = model.predict(X_pool)
```

如果原模型不能直接输出不确定性，必须明确使用的是深度集成、Bootstrap、树间方差、MC Dropout、共形预测还是其他方法。

## 5. 计算采集分数

常见策略分成两类：

- 两类都必须有 Random 随机基线；
- AL：Uncertainty、QBC、core-set、GSx/GSy/iGS、代表性与多样性；
- BO：Greedy、UCB/LCB、EI、PI、Thompson Sampling、EHVI；
- 批量策略：两类都可加入 Diversity，避免一批样本过于相似。

例如最大化问题的 UCB：

\[
\mathrm{UCB}(x)=\mu(x)+\beta\sigma(x)
\]

UCB 同时包含均值和不确定性，常用于 BO。只有论文的目标是改善全局模型且主要报告预测指标时，才可按作者定义将它计入 AL。所有策略都必须与 Random 基线比较。

## 6. 选择一批候选

真实材料实验往往是批量完成的。每轮推荐不仅要给编号，还要保存：

- 预测均值；
- 不确定性；
- 采集分数；
- 推荐原因；
- 模型版本；
- 数据版本；
- 时间戳。

如果研究同时追求模型学习和材料优化，可将一批候选分为探索、优化和多样性三部分，但必须预先规定比例，不能根据结果临时修改。

## 7. 调用 Oracle

离线复现：

```text
从完整公开数据中揭示被选候选的隐藏标签
```

真实闭环：

```text
导出推荐表 → 材料组实验 → 质控 → 回填标签和条件
```

失败实验也必须记录，不能无痕删除，否则会造成幸存者偏差。

## 8. 更新并循环

```text
新标签加入已标注集
→ 从候选池移除已测试样本
→ 重新训练或更新模型
→ 重新计算不确定性与采集函数
→ 选择下一批
```

停止条件可以是预算耗尽、达到目标性能、模型指标稳定或连续多轮没有改进。

## 9. 统一评价

### 预测能力

- MAE；
- RMSE；
- \(R^2\)；
- 负对数似然或其他概率指标；
- 不确定性覆盖率和校准。

### 材料发现能力

- best-so-far；
- simple regret；
- 找到前 1% / 5% 候选所需的标签数；
- top-k 命中率；
- 相对 Random 的加速比。

### 稳定性

- 多个随机种子；
- 均值、标准差和置信区间；
- 不同初始样本；
- 分组或结构划分，避免相似材料泄漏。

## 10. 最小伪代码

```python
labeled = initialize(candidate_pool)
unlabeled = candidate_pool - labeled

while not stop_condition:
    model.fit(labeled.features, labeled.targets)
    mean, uncertainty = model.predict(unlabeled.features)
    scores = acquisition(mean, uncertainty)
    selected = select_batch(unlabeled, scores)
    new_results = oracle(selected)
    labeled = labeled + new_results
    unlabeled = unlabeled - selected
    evaluate_and_log()
```

读每篇论文时，都要能指出它如何实现这十行逻辑。
