# 从论文复现到真实实验

## 三层工作必须分开

### A. 论文忠实复现

目标是确认作者公开结果能否在固定环境中重现。此时不擅自更换数据划分、模型、指标或采集函数。

### B. 统一基准比较

将论文方法接入统一接口，在相同数据、初始点、批量大小、标签预算和随机种子下比较。只有这一层才能公平判断方法优劣。

### C. 真实材料闭环

把离线 Oracle 换成实验或模拟。真实闭环必须增加实验失败、测量噪声、批次效应、制备约束和安全约束。

## 推荐的研究推进方式

```text
论文原始代码
    ↓ 忠实复现
论文结果复核
    ↓ 统一接口
跨论文基准
    ↓ 替换数据适配器
新材料公开数据
    ↓ 小规模试运行
真实实验闭环
```

## 从公开材料迁移到粘合剂

主动学习核心模块不应依赖“粘合剂”这个名称。迁移时主要更换：

- 输入适配器：配方、SMILES、实验条件和物理描述符；
- Oracle：粘合剂实验；
- 约束：可制备范围、安全规则、比例和工艺窗口；
- 目标：强度、模量、Tg、耐久性等；
- 物理模块：固化动力学、传热、扩散或本构关系。

保持不变的部分：

- 已标注/未标注管理；
- 模型接口；
- 不确定性接口；
- 采集函数；
- 日志、预算和停止条件；
- 评价协议。

## 真实实验前的最低检查

1. 化学组确认每一个输入字段是否能稳定记录；
2. 明确目标性能的测试标准、单位和方向；
3. 设置重复实验或标准样估计噪声；
4. 固定训练数据版本，禁止手工覆盖原始记录；
5. 推荐结果必须由材料专家审核后执行；
6. 失败、缺失和异常实验保留原始记录及处理理由；
7. 不把模型外推当作已验证材料结论。

## 什么时候使用 GNN

只有在候选具有可靠结构表示时使用，例如 SMILES、分子图或晶体结构。数据极少时优先：

```text
预训练 GNN embedding + GP/RF
```

而不是从零训练一个大型 GNN。

## 什么时候使用 PINN

只有化学或材料组确认了可信的方程、边界条件和参数定义后使用。对于粘合剂，PINN更可能负责固化过程，而不是直接替代配方性能模型。

## 何时可以声称“算法改进”

至少满足：

- 在多个公开材料数据集上与强基线公平比较；
- 使用多个随机种子和预先定义的预算；
- 同时报告预测质量、发现速度和不确定性校准；
- 做消融实验，确认改进来自哪个模块；
- 在至少一个新材料体系或真实实验上验证迁移；
- 文献检索表明组合或策略不是已有工作的简单重复。
